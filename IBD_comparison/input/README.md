#### Directory containing the input files for comparing with IBD
Files include:
1. all_webtwas.xlsx --- excel file of TWAS genes obtained from the TWAS database
2. gene_keys_ib_rna_seq.npy --- numpy array of the keys for the genes in the ibd dataset
3. gene_perturbations.gctx --- cmappy gctx file containing the transcriptional response to the gene perturbations; this is the $B$ matrix before being projected onto the causal eigengenes. *** LARGE FILE AVAILABLE AT DRYAD ***
4. gutjnl-2023-July-72-7-1271-inline-supplementary-material-1.xlsx --- excel file of the differentially expressed genes contained derived from the IBD dataset; this file is derived with the supplementary material of doi: [https://doi.org/10.1136/gutjnl-2021-326451].
5. mart_export.txt.gz --- gzipped csv file of the ENSEMBL IDs and their Entrez gene symbols
6. README.md --- this file
7. twas_atlas_downloadgenes.txt --- genes downloaded from the TWAS Atlas
8. TWASAtlas_IBD_all.csv --- twas genes associated with IBD
9. uopt_IBD_forward_df.csv.gz --- csv file containing a DataFrame of the optimal $u_{opt}$ vectors for 2,500 point-to-point optimizations
10. webTWAS_IBD.xlsx --- IBD-related genes downloaded from the webTWAS database
11. Xr_ibd.npy --- numpy array containing IBD-related expression data generated by the autoencoder *** LARGE FILE AVAILABLE AT DRYAD ***
